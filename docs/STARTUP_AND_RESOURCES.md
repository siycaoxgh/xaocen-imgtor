# 启动、自启动与资源占用

## 开机自启动

设置页的“开机自启动”使用当前用户注册表启动项：

- 开启后，登录 Windows 时自动启动晓枨图像工具及截图监听。
- 关闭后只删除 XAOCEN ImgTor 自己创建的启动项，不影响其他软件。
- 源码运行时使用 `pythonw.exe`，避免登录时弹出终端窗口。
- EXE 运行时直接注册当前 EXE 的绝对路径；移动便携版后，需要重新开启一次来更新路径。
- 该设置不需要管理员权限，也不写入 PyInstaller 临时解压目录。

## 发布包体积

PyInstaller 构建配置排除了项目未使用的 NumPy、Matplotlib、Pandas、SciPy 和 pytest 可选依赖。Pillow、pywebview、pynput、pystray、Tk 和项目实际运行模块仍然保留。

发布前应分别检查单文件 EXE、Portable ZIP 和 Inno Setup 安装包的大小，并以“启动、截图、托盘、插件检测、设置保存”回归测试为准，不能只依据压缩包大小判断兼容性。

## 运行内存

主界面由 pywebview/WebView2 提供，空闲内存主要来自浏览器运行时；截图监听、托盘和插件进程只在需要时工作。图片或视频预览会暂时增加内存，关闭预览后由运行时回收。当前版本的目标是避免常驻加载 FFmpeg、视频帧和大图原始数据，而不是承诺固定的单一内存数值。
