# XAOCEN ImgTor

晓枨图像工具：轻量 · 高效 · 专注于图像效率。

用于快速截图、动态图像录制、图片浏览、裁剪处理以及多格式导出。

## 运行

- Python 源码：双击 `启动.bat`
- 免安装发行版：运行 `release/XAOCEN-ImgTor.exe`
- 便携 ZIP：见 `release/XAOCEN-ImgTor-v4.9.0-portable.zip`

可选插件使用 `.xaocen-plugin` 分发包，放入设置页显示的插件目录后刷新即可。程序会校验包内 SHA-256 并解包。
